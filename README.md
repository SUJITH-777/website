# Swarn Aayu — website

Marketing site for **Swarn Aayu Foundation**: Aayu, Curiosity Coach, and Thinking Matters.

## Stack

Vite, React, TypeScript, Tailwind CSS, shadcn/ui.

## Local development

```sh
npm install
npm run dev
```

Build: `npm run build` · Preview: `npm run preview`

## Deployment

Configure your host (e.g. Vercel) to run `npm run build` and serve the `dist` output. Add `public/og.png` (or your chosen asset) and wire `og:image` / `twitter:image` in `index.html` when you have a canonical site URL for social previews.
